# Change Log

All notable changes to the "thatdatapurple" extension will be documented in this file.

## [2026.10.0]

- Recoloured to the 2026 That Data Person branding: brand-dark workbench, brand-purple status bar and selection, light-purple focus and accents.
- Rewrote the theme from the shared ThatDataPurple palette instead of a copied default-dark base.
- All text colours meet WCAG 2.2 AA (4.5:1) on the editor, current line and selection; focus indicators meet 3:1.
- Added semantic token colours, bracket-pair colours, terminal ANSI colours and diff/merge colours.

## [2022.2.3]

- Initial release
